## Built for how people actually work

Not a reskin of 1995 metaphors. Interfaces should reflect how people actually use computers today — or could use them tomorrow.

## Simple by default, powerful on demand

A non-technical person should never see a terminal unless they want to. An expert should never feel the OS is holding them back.

## Updates that never break trust

No user should ever fear an update. Atomic, reversible, tested before it reaches you — updating should feel as safe as closing a laptop lid.

## Use what exists, build what's missing

No reinvented wheels, no "just rewrite it in Rust" as a strategy. Use existing software when possible, write new software when necessary.
