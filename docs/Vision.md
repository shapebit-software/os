# Vision

## Built for how people actually work

Not a reskin of 1995 metaphors. Interfaces should reflect how people actually use computers today — or could use them tomorrow.

## Simple by default, powerful on demand

A non-technical person should never see a terminal unless they want to. An expert should never feel the OS is holding them back.

## Updates that never break trust

No user should ever fear an update. Atomic, reversible, tested before it reaches you — updating should feel as safe as closing a laptop lid.

## Use what exists, build what's missing

No reinvented wheels, no "just rewrite it in Rust" as a strategy. Use existing software when possible, write new software when necessary.

## Find a sustainable way to build

Lasting development needs funding and people who can work on it full-time. We don't yet know how ShapeBit will be received, or how AI and easier reverse engineering will change software business models. We chose the PolyForm Shield License to leave room for future funding, but we don't know whether it's the best approach. We're still experimenting and open to suggestions.

## Free to use, easy to make your own

ShapeBit base OS should always be free of charge. You should be able to explore, modify, and adapt the OS to your needs. As AI makes tailored software easier to build, ShapeBit should make it easy to create your own tools and change how your system works.
