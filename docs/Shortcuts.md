# Shortcuts

**Super** is the Windows key (⌘ on Apple keyboards). **Super+/** shows all
shortcuts on a picture of the keyboard.

## Windows

| Shortcut | Action |
|---|---|
| Alt+Tab, Alt+Shift+Tab | Switch to the next or previous window |
| Alt+\`, Alt+Shift+\` | Switch among the app's windows |
| Super+arrows | Focus the window beside, or the next screen |
| Super+Shift+arrows | Swap the window with the one beside, or move it to the next screen |
| Super+F | Full screen |
| Super+W | Window menu |
| Super+Q | Close the window |

In the window switcher, let go of Alt or press Enter to switch, Q to close
the window that's selected, and Escape to cancel.

## Workspaces

| Shortcut | Action |
|---|---|
| Super+Alt+←/→ | Previous or next workspace |
| Super+Alt+Shift+←/→ | Move the window to the previous or next workspace |
| Super+1…8 | Go to a workspace |
| Super+Shift+1…8 | Move the window to a workspace |

Moving a window past the last workspace makes a new one, up to eight.

## Desktop

| Shortcut | Action |
|---|---|
| Super | Assistant: tap to open or close it, hold while you speak, or double-tap for voice mode, which listens until you say "stop" or tap again |
| Super+A | Apps |
| Super+D | Dictate: tap to start and stop, or hold while you speak |
| Super+N | Notifications |
| Super+I | Settings |
| Super+L | Lock the screen |
| Ctrl+Alt+Delete | System menu |
| Super+Space, Super+Shift+Space | Next or previous keyboard layout |
| Super+/ | Keyboard shortcuts |

## Screenshots and recordings

| Shortcut | Action |
|---|---|
| Print | Take a screenshot or a recording |
| Alt+Print | Capture the focused window |
| Super+Print | Capture the screen |
| Shift+Print | Start a recording, or stop one |

## Media keys

Volume, mute, microphone mute, play and pause, next and previous track, and
brightness keys work, on the lock screen too.

Shortcuts work by the position of the key, whatever keyboard layout is in use.
Alt+F4, F11, and other shortcuts of apps are left to the apps.
